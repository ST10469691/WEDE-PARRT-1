# Sisco Solutions Website

This repository contains the source code for the official Sisco Solutions website — a Johannesburg-based accredited baking school. The website showcases our courses, services, and contact details for prospective students and partners.
About the Website
This is the official website for Sisco Solutions, an accredited baking school based in Johannesburg. It introduces the school’s story, mission and vision, showcases accredited courses, cake events and business consulting services, and provides an easy way for visitors to get in touch via a contact form, phone, email and social media. The site is built with HTML, CSS, features new images and a hero video, and uses a responsive design so it looks and works great on desktops, tablets and phones.

##  Project Structure

 Features
- Responsive layout for mobile and desktop.
- Hero video banner on the homepage.
- Information about accredited courses, events, and business consulting.
- Contact form with phone, email, and address details.
- Integrated social media links (Facebook, Instagram, TikTok).


## Technologies Used
- HTML5 for structure.
- CSS for styling.
- Font Awesome for icons.
- Animate.css for animations.


##  Current Colours
- Background: White / Light Neutral (was Pink in Part 1)
- Primary Text: Dark Gray / Black
- Accent / Buttons: Current accent colour used in your CSS (fill in from `style.css` once known)
- Links & Icons: Branded colours from social platforms (Facebook blue, Instagram gradient, TikTok black/red/blue)
